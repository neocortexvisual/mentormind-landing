1. Escopo visual
   Implemente apenas o que a tarefa pede. O print é referência:
   elementos visíveis fora do escopo servem apenas de contexto.

2. Arquitetura mínima
   Use a estrutura existente e altere apenas os arquivos permitidos
   na tarefa. Crie um arquivo somente se for indispensável para
   concluir o pedido e couber na estrutura prevista. Não crie novas
   pastas, instale dependências ou preencha arquivos vazios por
   antecipação. Se precisar sair do escopo, informe o motivo e faça
   o que for possível dentro dele.

3. Responsabilidade de cada arquivo
   A página compõe; a seção apresenta; a feature cuida da interação.
   Estilos específicos ficam na seção. Reutilize os tokens existentes.
   Extraia um componente compartilhado quando houver uso real em
   mais de um lugar. Use Astro para a estrutura, React para a
   demonstração e Three.js para a cena 3D.

4. Responsividade
   Use a mesma estrutura HTML no celular e no desktop. Se o projeto
   rodar, confira em 360 px e 1440 px. Corrija o overflow onde ele
   nasce; não esconda rolagem horizontal no body.

5. Entrega
   Leia o README, inspecione só o necessário e finalize com:
   arquivos alterados, verificação e pendências.
